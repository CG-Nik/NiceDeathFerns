# NiceDeathFerns
This mod destroys certain types of Death Ferns when they spawn, allowing you to not have to deal with them.
This mod only needs to be on the Server to work properly, and has no effect on the Client.  

By default, this mod destroys Death Ferns and Vine Attack Ferns, but not Mother Ferns.  
To edit which types of Death Ferns it destroys, go to UserData/MelonPreferences.cfg in the server's game files, then change the values in the NiceDeathFerns category.  
Setting a value to "true" causes it to destroy said type of Death Fern, and "false" causes that type of Death Fern to not be destroyed.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
